REST API Reference

Programmatic access to TrendIQ's forecasting, sentiment, and benchmarking endpoints.

POST

/predict

Generates multi-horizon price projections (1d, 7d, 30d), uncertainty bands, and real-time news sentiment for a given stock ticker.

Parameters (Form Data / URL-encoded):

  • ticker (string, required): US equity ticker symbol (e.g. AAPL, NVDA, MSFT).

Sample Response:

{
  "ticker": "AAPL",
  "current_price": 314.58,
  "predicted_price": 314.81,
  "price_change": 0.23,
  "price_change_pct": 0.07,
  "trend": "up",
  "horizons": {
    "1d": { "price": 314.81, "upper_80": 320.32, "lower_80": 309.30, "upper_95": 323.25, "lower_95": 306.37 },
    "7d": { "price": 315.40, "upper_80": 329.98, "lower_80": 300.82, "upper_95": 337.74, "lower_95": 293.06 },
    "30d": { "price": 318.20, "upper_80": 348.87, "lower_80": 287.53, "upper_95": 364.96, "lower_95": 271.44 }
  },
  "sentiment": {
    "score": 0.40,
    "label": "Bullish",
    "articles": [...]
  },
  "benchmark": {
    "model_rmse": 5.52,
    "naive_rmse": 5.53,
    "model_mape": 1.34,
    "directional_accuracy": 54.8
  }
}
GET

/live-ticker

Fetches real-time price quotes and daily percentage changes for popular market assets in a single bulk query.

Sample Response:

[
  { "symbol": "AAPL", "price": 314.58, "change": 1.13, "changePercent": 0.36 },
  { "symbol": "NVDA", "price": 227.98, "change": -2.40, "changePercent": -1.04 },
  { "symbol": "MSFT", "price": 505.06, "change": 8.69, "changePercent": 1.75 }
]
GET

/api/benchmarks

Returns the pre-computed out-of-sample empirical benchmark results comparing Ridge ML against the Naive Random Walk baseline.
