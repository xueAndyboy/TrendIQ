🛠️ Architecture Overview

TrendIQ is built as a serverless Python web application designed for fast, reproducible time-series inference:

  • Frontend: Clean vanilla JavaScript, CSS3 with modern glassmorphism, responsive Chart.js visualizer.
  • Backend Server: Flask WSGI application deployed to Vercel Serverless Functions (`@vercel/python`).
  • Market Data Engine: Live and historical market data ingested directly from Yahoo Finance via `yfinance` and `curl_cffi`.
  • Quantitative Engine: Scikit-learn Ridge Autoregressive pipeline with dynamic lag engineering and residual error variance bands.
  • Sentiment NLP: Financial lexicon polarity analyzer evaluating real-time ticker news.

💻 Local Setup & Development

To run TrendIQ locally on your development machine:

# 1. Clone the repository
git clone https://github.com/Simarjot846/TrendIQ.git
cd TrendIQ

# 2. Create and activate a virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# 3. Install required dependencies
pip install -r requirements.txt

# 4. Run the quantitative evaluation pipeline (optional)
python backend/evaluate_pipeline.py

# 5. Start the local server
python app.py

Access the web application in your browser at http://127.0.0.1:5000.

📊 Reproducing Benchmark Evaluations

The empirical benchmark results shown across the application are fully reproducible. Run the standalone pipeline script:

python backend/evaluate_pipeline.py

This script downloads 2 years of daily data, applies the strict chronological 80/20 train/test split, calculates metrics against the Naive baseline, and writes the output directly to data/benchmark_results.json.
